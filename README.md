Um projeto básico em **C++** que demonstra como ler, analisar, modificar e reconstruir arquivos **Prefetch (.pf)** do Windows.

> **Apenas para fins educacionais.**
> Este projeto foi desenvolvido com o objetivo de estudar a estrutura interna dos arquivos Prefetch, técnicas de compressão utilizadas pelo Windows e o funcionamento de APIs de baixo nível da WinAPI e NTDLL.

### 🫆 Funcionalidades

* Leitura de arquivos Prefetch (.pf)
* Suporte a arquivos Prefetch compactados
* Análise da estrutura interna do arquivo
* Processamento dos registros de acesso armazenados
* Remoção de entradas selecionadas
* Reconstrução e recompressão do arquivo
* Preservação dos timestamps originais
* Utilização das APIs nativas de compressão do Windows (NTDLL)
